# 中农大数据二学位两年学习陪跑 Skill

面向中国农业大学数据科学与大数据技术第二学士学位学生的学习陪跑 Skill。

它不是招生咨询库，也不是入学考试备考库，而是给已经录取或即将入学的同学使用：帮助大家在两年压缩培养中更快理解课程节奏、作业实验、期末复习、课程项目沉淀，以及就业、考研、考公之间的取舍。

## 前言

进入第二学士学位以后，很多信息并不难，却常常分散在课表、群聊、往年经验、课程作业、项目材料和学长学姐口头提醒里。

有些同学刚开始接触编程、数学、数据库、操作系统和机器学习，会不知道每门课到底该学到什么程度；有些同学一边上课一边准备考研、考公或实习，会不知道哪些课要认真吃透，哪些课先保住作业和期末；也有些同学做完课程项目以后，才发现这些经历本来可以沉淀成简历、复试或面试材料。

这个项目想做的事情很简单：

把前人走过的弯路、踩过的坑和总结过的方法，整理成公开、脱敏、可持续更新的学习资料。

希望后来的同学不用每年从零开始摸索，也不用靠运气等别人刚好在群里回答。

## 这个项目是什么

本仓库收录一个 Codex Skill：

```text
marvel-bigdata-two-year/
```

它可以辅助回答：

- 第一至第三学期应该怎么学
- 零基础或弱基础怎么适应大数据专业课
- Python、C、Excel、统计、离散、Linux、Web、数据结构、数据库、操作系统、计组、数据挖掘、机器学习等课程怎么安排
- 作业、实验、期末、实习、考研、考公怎么取舍
- 课程项目怎么整理成简历、复试、面试表达
- 新经验如何脱敏后补充进资料

暂不包含：

- 招生资格判断
- 报名材料
- 入学考试备考
- 分数线预测
- 补录调剂
- 个人陈述
- 法学、英语、会计、传播学等其他二学位专业
- 第四学期毕业设计与离校细化指南

## 文件结构

```text
marvel-bigdata-two-year/
├── SKILL.md

    ├── semester-1.md
```

其中：

- `SKILL.md`：Skill 的主说明与路由规则。
- `semester-1.md`：第一学期学习策略。
- `semester-2.md`：第二学期学习策略。
- `semester-3.md`：第三学期学习策略。
- `projects.md`：课程作业、实验、大作业如何沉淀成项目表达。
- `privacy-and-updates.md`：资料更新、来源可信度和脱敏规则。

## 使用方法

把 `marvel-bigdata-two-year` 文件夹放到 Codex 的 skills 目录中，然后在对话里使用：

```text
使用 $marvel-bigdata-two-year：第一学期应该怎么学？
```

或：

```text
使用 $marvel-bigdata-two-year：我零基础，第二学期数据结构和数据库怎么保住？
```

或：

```text
使用 $marvel-bigdata-two-year：我偏就业，课程项目怎么整理成简历？
```

## 脱敏与边界

请不要上传：

- 原始群聊记录
- 未授权课件、试卷、答案、题库
- 盗版电子书或付费资料
- 老师私人联系方式
- 同学姓名、昵称、微信号、手机号、学号、群号
- 能够定位到个人的完整背景和录取/就业/升学结果
- IMA、网盘、内部群、私有资料库的访问链接或密钥

可以上传：

- 脱敏后的共性经验
- 自己撰写的学习策略
- 对公开信息的整理
- 课程项目复盘模板
- 不含隐私的 Q&A

如涉及当年课程要求、考核方式、截止日期、评分比例，请始终以任课老师和学院当年通知为准。
