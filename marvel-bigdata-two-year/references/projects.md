# 课程作业到项目表达

这个文件用于回答“课程作业能不能写简历/复试/面试”“项目怎么整理”“我没有实习怎么办”等问题。回答时不要把普通课程作业包装成生产级项目，要把真实完成过的内容翻译成可理解、可验证的项目表达。

## 项目提取模板

整理任何课程项目时，先让学生补齐这些信息：

```text
项目名称：
问题背景：
数据来源：
技术栈：
我负责什么：
核心实现：
结果：
遇到的问题：
改进方向：
```

如果用户信息很少，先用“课程作业复盘版”回答，不要直接编造数据、指标或成果。

## 课程到项目示例

### Python / Excel / 数据分析

Weak:
完成 Python 和 Excel 作业。

Better:
基于公开数据完成清洗、统计分析和可视化，使用 pandas/Excel 处理缺失值、异常值和分组统计，输出分析报告。

可补充追问：

- 数据来自哪里？
- 做过哪些清洗？
- 输出了哪些图表或结论？
- 有没有代码、报告、截图？

### 数据库 / SQL

Weak:
学过数据库。

Better:
设计并实现课程管理数据库，完成 ER 建模、表结构设计、SQL 查询、分组统计和基础索引优化。

可补充追问：

- 业务场景是什么？
- 有几张表？核心字段是什么？
- 写过哪些 SQL？
- 有没有 ER 图、建表脚本、查询结果截图？

### 数据挖掘 / 机器学习

Weak:
做过机器学习课程项目。

Better:
基于某公开数据集完成分类/预测任务，对比多种模型，使用准确率、召回率或 F1 等指标评估，并分析误差来源。

可补充追问：

- 是分类、回归、聚类还是关联规则？
- 数据量大概多少？
- 用了哪些特征？
- 指标是多少？为什么效果好/不好？

### Web / 可视化

Weak:
做过网页。

Better:
实现一个包含页面展示、表单输入、数据查询或可视化的 Web 小系统，说明前端结构、数据流和交互逻辑。

可补充追问：

- 页面解决什么问题？
- 有没有交互？
- 数据从哪里来？
- 是否有截图或部署链接？

## 最小作品集

就业向学生，尽量在前三学期结束前整理出：

- 一个 Python/SQL 数据分析项目。
- 一个数据库或 Web 小系统项目。
- 一个机器学习/数据挖掘/可视化项目。

考研向学生：

- 项目不必做得很商业化，重点是复试能讲清楚。
- 保留“为什么做、怎么做、结果如何、遇到什么问题”。
- 可以把课程项目作为跨专业学习能力证明。

考公/考编向学生：

- 项目材料以备用为主，不要抢占主线备考时间。
- 可以保留一两个能体现学习能力、数据能力、组织能力的材料。

## 表达强度边界

可以说：

- “课程项目”
- “学习项目”
- “基于公开数据的分析实践”
- “完成了数据清洗、建模、可视化和结果分析”

谨慎说：

- “企业级”
- “上线系统”
- “生产环境”
- “负责核心架构”
- “显著提升业务指标”

除非用户确实做过并能提供证据，否则不要夸大。

## 回答模板

```text
先说结论：这个可以整理成项目，但建议按学习项目表达，不要夸大。

可以这样拆：
1. 项目背景：
2. 你做了什么：
3. 用到的技术：
4. 结果和材料：
5. 简历/复试表达：

下一步你要补齐：
- 数据/代码/截图/报告
- 指标或结果
- 遇到的问题和改进
```
