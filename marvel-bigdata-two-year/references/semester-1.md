# 第一学期陪跑指南

适用对象：中农大数据二学位第一学期在读或即将入学学生。

回答口吻：学长学姐式，先给结论，再讲理由，最后给下一步动作。

信息说明：本文件基于往届课程资料、课表和脱敏经验整理。课程安排、任课老师、考核方式和具体要求每年可能变化，涉及考试范围、成绩构成、免修、补考、重修、奖学金等规则时，必须提醒以当年老师要求、学生手册和学院/教务通知为准。

## 1. 第一学期整体特点

一句话定位：相对后续计算机核心课和方向课，第一学期更偏入门；但任务量并不少，真正难点是节奏、题量和细节。

### 1.1 授课模式

- 二学位课程常见模式是一个时间段集中上一门或几门课，学完一段、考核一段，再进入下一段。
- 课表可能通过班级群发布 Excel 班课表，教务系统里不一定能按普通本科方式查到完整节奏。
- 按往年经验，第一学期可能涉及程序设计、Excel、数理统计、Python、离散数学、Linux、Web、最优化等模块，具体顺序以当年课表为准。

### 1.2 考核总规律

先说结论：期末题型和平时作业、实验、PPT 例题、教材课后题关系通常很密切，常见原题或变式。想稳住成绩，不能只靠考前突击，平时作业和实验最好自己完整做一遍。

常见考试类型：

| 类型 | 说明 |
| --- | --- |
| 上机考试 | 编程类课程常见，可能开卷或闭卷 |
| 试卷考试 | 可能闭卷、半开卷或开卷 |
| 实验/大作业 | 通常看过程、代码、报告和最终结果 |

### 1.3 开学就要想清楚的事

1. 免修：免修、成绩、奖学金等具体影响以当年规定为准。有些能免修的课也可能是比较容易拿高绩点的课，申请前要结合自己的目标判断。
2. 方向：就业向越早确定大致技术方向越好；考研/考公向要提前意识到第一学期课程密度不低，课程和主线备考需要取舍。

## 2. 课程逐门攻略

每门课按“讲什么 -> 怎么考 -> 三档策略 -> 常见误区”组织。回答“这门课难不难/要不要预习/怎么复习”时，先定位它属于哪类能力，再给保底或强化策略。

### 2.1 程序设计（C 语言）

#### 讲什么

课程通常从零基础到指针、结构体、文件等内容，覆盖面较广但深度可控。

| 模块 | 核心内容 |
| --- | --- |
| C 程序基础 | 程序结构、main 函数、编译运行、常量变量、数据类型 |
| 三种结构 | 顺序结构、选择结构、循环结构、break/continue、循环嵌套 |
| 数组 | 一维/二维数组、遍历、求最值、排序查找、字符串 |
| 函数 | 定义、声明、调用、形参实参、值传递、数组作参数 |
| 指针 | 取地址、间接访问、指针与数组、字符指针等基础内容 |
| 结构体与文件 | 结构体、结构体数组/指针、文件读写 |

必会经典题型包括：累加、累乘、阶乘、Fibonacci、判断素数、判断闰年、排序、求最值、数组逆序、矩阵转置、递归、日期合法性判断、字符和 ASCII 码处理等。

#### 怎么考 & 三档策略

- 考核：期末可能为上机考试，难度通常高于平时作业，但一般不脱离平时训练。
- 最低保底：平时作业认真做，考试能写出基础题和部分综合题，不要空白。
- 正常学习：开学初预习基础语法、循环、数组、函数；上课作业尽量当天完成。
- 就业强化：如果走开发、数据开发或机试方向，学完 C 基础后接数据结构/面向对象，并开始基础刷题；如果走数据分析方向，不必把 C 卷成主线，优先保证课程过关。

常见误区：作业攒到期末一起补。代码课堆起来会非常痛苦，而且期末上机靠临时看答案很难稳。

### 2.2 Excel 数据处理

#### 讲什么

Excel 可以当作第一门数据处理工具课。

| 模块 | 核心内容 |
| --- | --- |
| 公式与函数 | 相对/绝对引用、IF、COUNTIF/SUMIF、VLOOKUP、统计函数 |
| 数据管理 | 数据验证、排序、筛选、高级筛选、分类汇总、合并计算 |
| 图表 | 柱形图、折线图、饼图、散点图、数据透视图 |
| 数据透视表 | 筛选、行、列、值四区域，汇总方式和值显示方式 |
| 假设分析 | 单变量求解、模拟运算表、方案管理器 |
| 规划求解 | 决策变量、目标函数、约束条件 |
| 统计分析 | 描述统计、方差分析、相关分析、回归分析和输出解读 |

典型题型可能包括：公式函数、透视表、模拟运算表、规划求解、方差分析、回归分析等。

#### 怎么考 & 三档策略

- 考核：可能开卷、上机或在自己电脑上操作，具体以当年老师要求为准。题量可能较大，不熟练容易做不完。
- 最低保底：把老师给的实验和案例完整操作一遍。
- 正常学习：平时实验全部自己动手，重点掌握后段的规划求解、假设分析、回归等内容。
- 就业强化：Excel 是数据分析岗的实用技能，函数、透视表、规划求解、回归分析都可以沉淀成技能证明或小项目材料。

常见误区：以为开卷就稳。开卷只能帮你查，不能替你熟练操作。

### 2.3 应用数理统计/数理统计

#### 讲什么

课程主线一般是“描述统计 -> 概率与分布 -> 统计推断 -> 统计应用”。

| 模块 | 核心内容 |
| --- | --- |
| 数据概括 | 均值、中位数、众数、方差、标准差、偏态、峰态 |
| 概率与分布 | 随机事件、离散/连续分布、正态分布 |
| 抽样分布 | 样本均值分布、中心极限定理、t/F/卡方分布 |
| 参数估计 | 区间估计、一个/两个总体参数估计、样本量确定 |
| 假设检验 | 原假设/备择假设、P 值、两类错误、单/双总体检验 |
| 分类数据分析 | 卡方检验、拟合优度、列联分析 |
| 方差分析 | 单因素、双因素方差分析 |
| 回归分析 | 一元/多元线性回归、显著性、预测、残差 |
| 时间序列 | 趋势、平稳、分解和预测 |

#### 怎么考 & 三档策略

- 考核：往年经验看，题目与老师重点、作业、教材课后题和课堂例题关系较大。
- 最低保底：老师划的重点和对应课后题认真做一遍。
- 正常学习：重点掌握区间估计、假设检验、回归分析的题型判断。
- 就业/考研强化：统计是数据分析、机器学习和统计学习的前置，P 值、假设检验、回归等概念值得真正理解。

常见误区：只背最后范围。概念题可能来自上课讲过但没有被你当成“重点”的内容。

### 2.4 Python 程序设计

#### 讲什么

课程主线通常是“基础语法 -> 数据分析库 -> 综合大作业”。

| 模块 | 核心内容 |
| --- | --- |
| Python 基础 | 数据类型、控制流、函数、列表、字典、文件读写、CSV |
| NumPy | 数组创建、索引、reshape、基础运算 |
| pandas | Series/DataFrame、文件读写、清洗、筛选、排序、分组聚合 |
| matplotlib | 基础可视化图表 |

期末或大作业可能围绕一个数据集完成读取、清洗、统计、可视化和分析报告。

#### 怎么考 & 三档策略

- 考核：可能包括平台编程作业、机房考试、大作业等，具体以当年老师要求为准。
- 最低保底：把平台作业和课堂案例全部自己写一遍，代码题通常会从这些内容变形。
- 正常学习：重点吃透数据读取、清洗、分组统计、可视化。
- 就业强化：Python 大作业非常适合做简历项目素材，保留数据、代码、图表、报告和问题记录。

常见误区：光看视频不动手。代码题是要自己写出来的，看会不等于会写。

### 2.5 离散数学

#### 讲什么

往年经验中，离散数学可能以图论为主体，也可能按当年老师调整。回答时不要说死，重点提醒以当年课程安排为准。

常见内容包括：

| 模块 | 核心内容 |
| --- | --- |
| 图的基本概念 | 无向图、有向图、度数、完全图、简单图 |
| 握手定理 | 度数和、奇度顶点、度数序列、边数互推 |
| 图间关系 | 子图、生成子图、补图、同构 |
| 路与回路 | 通路、回路、连通性、割点、桥 |
| 矩阵表示 | 邻接矩阵、可达矩阵 |
| 欧拉图/汉密尔顿图 | 判定、构造、典型应用 |
| 平面图 | 欧拉公式、平面图判定相关结论 |
| 树与应用 | 生成树、最小生成树、哈夫曼树、前缀码 |

#### 怎么考 & 三档策略

- 考核：可能有简答、证明、应用、计算等题型；与作业、PPT 例题、课后题关系较大。
- 最低保底：作业按时交，期末把作业题、PPT 例题、课后题过一遍。
- 正常学习：概念配合图来学，证明题先掌握模板。
- 考研强化：如果目标院校考离散或相关内容，认真学不亏；否则以课程保底和概念理解为主。

常见误区：轻视作业截止时间。离散靠期末临时看概念不太稳，题要做。

### 2.6 Linux

#### 讲什么

Linux 是“系统概念 + 命令行实操”两条线。

| 模块 | 核心内容 |
| --- | --- |
| 基础 | man、help、路径、文件系统 |
| 文件与目录 | ls、cp、mv、rm、cd 等 |
| 权限管理 | chmod、chown、权限位 |
| 用户与用户组 | useradd、userdel、usermod、groupadd、passwd 等 |
| Vim | 移动、删除、复制、粘贴、撤销、搜索、保存退出 |
| 进程管理 | ps、top、kill、sleep、nohup、wait、nice |
| 磁盘与压缩 | df、du、gzip、unzip、tar 等 |
| 编译与脚本 | gcc、shell 脚本基础 |

#### 怎么考 & 三档策略

- 考核：可能有理论和实验，实验通常需要写命令、实际操作和截图。
- 最低保底：理论梳理 PPT 概念，实验拿典型题练手。
- 正常学习：常用命令逐类敲一遍，重点是 Vim、用户管理、进程、压缩解压、权限。
- 就业强化：Linux 命令行和 shell 是后端、测试、数据开发、大数据岗常见基础，值得练熟。

常见误区：只背命令不敲。Linux 最有效的学习方法是自己建测试文件夹，把命令实际跑一遍。

### 2.7 Web 程序设计

#### 讲什么

Web 通常是前端三件套入门：HTML、CSS、JavaScript，以及表格、表单、DOM、页面布局等内容。

| 模块 | 核心内容 |
| --- | --- |
| HTML | 页面结构、常用标签、表格、表单、多媒体标签 |
| CSS | 选择器、盒子模型、边框、内外边距、背景、浮动、定位 |
| JavaScript | 基础语法、DOM 操作、表单交互 |
| 页面布局 | div 模块化、浮动定位、简单页面结构 |

#### 怎么考 & 三档策略

- 考核：可能包括理论选择题、开卷资料、实验填空或页面代码，具体以当年要求为准。
- 最低保底：教学平台实验源代码全部过一遍，理论资料提前整理。
- 正常学习：系统过 HTML/CSS/JS 基础，重点看盒模型、布局、表单、DOM。
- 就业强化：选前端方向的话，这门课只是起点，后续要自行补 Vue/React 和项目；非前端方向也可以把 Web 大作业作为展示层材料。

常见误区：以为开卷选择题就随便过。实验和代码部分不熟，仍然会丢分。

### 2.8 最优化方法

#### 讲什么

最优化通常围绕线性规划、无约束优化、约束优化等内容，计算题和方法流程比较重要。

| 模块 | 核心内容 |
| --- | --- |
| 线性规划建模 | 决策变量、目标函数、约束条件、标准型 |
| 单纯形法 | 单纯形表、检验数、进基/离基、迭代 |
| 人工变量法 | 大 M 法、二阶段法 |
| 对偶理论 | 写对偶问题、对偶最优解、互补松弛 |
| 无约束优化 | 一阶/二阶条件、最速下降、牛顿法 |
| 最优性条件 | KKT、Lagrange 乘子、互补松弛 |
| 约束优化算法 | 罚函数等基础思想 |

#### 怎么考 & 三档策略

- 考核：可能有基础概念和计算题，老师划重点时要优先围绕重点练。
- 最低保底：看速成课和典型题，重点练单纯形法、写对偶、KKT、牛顿法等常见题型。
- 正常学习：按题型分类复习，不建议临考从书第一页顺读。
- 就业向：如果不走算法/机器学习方向，优先保过；如果后续想做机器学习，可以补梯度下降和优化直觉。

常见误区：只练计算题、不看基础概念。基础概念题也可能是送分点。

## 3. 分人群策略

### 3.1 零基础/文科背景

- 开学前预习：C 语言基础语法、循环、数组、函数优先级较高。
- C 和 Python 前几周一定要跟紧，掉队后会影响后续数据处理。
- 心态上不要一直和科班或已有基础的同学比。第一阶段先做到能跑、能改、能解释。

### 3.2 数学弱

- 数理统计和最优化是两道坎。
- 数理统计：抓老师重点、课后题、假设检验和区间估计题型。
- 最优化：走“速成课 + 题型”路线，流程化题型多练。
- 不要第一轮死磕所有推导。

### 3.3 代码弱

- C、Python、Linux 的共同规律：考核往往和平时任务变形关系大。
- 作业和实验自己做一遍，是最稳的保底策略。
- 别完全照抄作业。期末上机或实验考核时，抄来的平时分救不了现场。

### 3.4 就业向

- 第一学期就可以开始了解岗位方向，但不必因为找不到实习否定自己。
- 寒假适合写第一版目标简历，把想补的技能和项目列出来，再倒推学习计划。
- 开发/数据开发方向可补数据结构和基础刷题；数据分析方向优先 Python、SQL、Excel、统计和项目表达。
- 实习渠道建议走正规平台，警惕收费培训、贷款培训、内推收费等风险。

### 3.5 考研/考公向

- 第一学期课程密度不低，全部深学和主线备考同时高强度推进会很累。
- 即使降低课程投入，也建议完成保底档：作业按时交、实验按时做、考前过重点。
- 挂科、补考、重修、毕业影响等具体规则以学校当年规定为准，不要只凭往年经验判断。

## 4. 期末复习优先级

通用流程：

1. 老师划的重点。
2. 平时作业和教材课后题。
3. PPT 例题。
4. 平台练习和实验源代码。
5. 往年题或题型回忆，用来熟悉题型和题量，不要过度押题。

很多课不是难在理解，而是难在任务多、题量大、细节杂。早点整理，期末会轻很多。

## 5. 第一学期可沉淀材料清单

| 材料 | 来源课程 | 用途 |
| --- | --- | --- |
| 基础刷题记录 | C 语言/后续自学 | 开发、数据开发、机试方向 |
| 数据分析报告 | Python 大作业 | 数据分析、复试、简历项目 |
| 函数/透视表/回归流程笔记 | Excel | 数据分析技能证明 |
| 静态网页或交互页面 | Web | 前端/展示型项目 |
| Linux 命令和 shell 练习 | Linux | 后端、测试、数据开发基础 |
| 离散/统计/最优化笔记 | 数学类课程 | 复习、考研、后续辅导 |

原则：每个大作业都留档，至少保留代码、截图、报告和一段“我做了什么”的说明。

## 6. 就业向：第一学期时间线

- 开学前：调研有哪些岗位，自己对什么方向感兴趣。
- 期中前后：可以开始写简历初稿，找不到实习很正常，不要因此否定自己。
- 寒假：写目标简历，倒推要补的项目和技能；初步确定技术方向。
- 第一学年暑假前：尽量沉淀至少一个能展示的数据/代码项目。
- 投递渠道：正规招聘平台、官网、实习平台、可靠公众号等。
- 防骗提醒：凡是以“你能力不行，交钱上课/贷款培训”为主要话术的，都要高度警惕。

方向提醒：

- 后端/数据开发学习成本较高，需要数据结构、数据库、Linux、计网等基础。
- 数据分析更重 Python、SQL、Excel、统计、可视化和业务表达。
- 前端需要在 Web 基础上继续补框架和项目。
- 测试/技术支持可以结合 Linux、数据库、计网和脚本能力。

## 7. 高频 Q&A

### Q：文科生学 Python 听不懂怎么办？

A：前几周语法过得快是主因。课前花一点时间预习当天语法点，课后把平台作业独立写一遍。到 NumPy/pandas 阶段会更偏操作化，但前面的基础语法不能完全断。

### Q：C 语言要学到什么程度？

A：课程层面，能独立写出循环、数组、函数的综合题即可保底；就业层面，如果走开发/数据开发/机试方向，学完基础后接数据结构和基础刷题。

### Q：Linux 怎么复习？

A：理论看 PPT 和概念，实验拿典型题练。命令按模块过：Vim、用户组管理、权限、进程、解压缩、文件操作。一定要自己敲命令。

### Q：Excel 需要认真学吗？

A：需要。它是第一学期性价比很高的课程，也是数据分析岗的实用技能。平时实验自己做，考前练速度。

### Q：统计听不懂推导怎么办？

A：考试导向先按“老师重点 + 课后题/作业题”刷题型。先知道公式什么时候用、题目怎么判断，再补推导。

### Q：第一学期课太多怎么安排？

A：记住“期末常常是平时任务变形”。作业当天清，实验当周清；期末按老师重点、作业、PPT 例题、平台练习和往年题型顺序复习。

### Q：电脑要换吗？Mac 行不行？

A：一般轻薄本够用。Mac 可能遇到部分课程软件或环境不方便的问题，可以用 Windows 虚拟机或备用 Windows 设备解决。具体看当年课程软件要求。

### Q：第一学期有小组作业吗？

A：按往年经验，第一学期小组作业压力相对不大，但每年课程可能调整，具体以任课老师要求为准。

### Q：要不要参加竞赛？

A：先看目标。如果就业向，可以选择和技术/数据方向相关、投入产出比高的竞赛。不要为了综测或奖项盲目报很多，先保证课程、项目和主线目标。
